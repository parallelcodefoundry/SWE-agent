Write a detailed implementation plan to .planning/PLAN-current.md.

Structure it as:

## Summary
What we're implementing and why (2-3 sentences)

## Bootstrap (READ THESE FILES BEFORE IMPLEMENTING)
List every file (with line ranges if large) that the implementing session MUST read before starting. Include a note next to each file saying WHY it needs to be read. Be exhaustive.

## Implementation Steps
Detailed steps. Frame code references as "verify in [file]" rather than asserting signatures from memory.

## Gotchas
Things the implementing session needs to watch out for.

## Verification
How to check the implementation is correct — test commands, expected behaviors, what to run on a compute node.

Add this warning at the top:
"⚠️ This plan was written by a previous session. All file paths and code references should be verified by reading the actual files listed in Bootstrap before implementing."
