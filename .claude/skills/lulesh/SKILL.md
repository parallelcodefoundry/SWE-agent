# LULESH

Livermore Unstructured Lagrangian Explicit Shock Hydrodynamics 2.0 -- Sedov blast wave on hex mesh, CUDA GPU, ~4800 lines C++.

## Source Location

- **Pristine**: `/pscratch/sd/k/krydzy/SWE-agent/Lulesh/cuda/` (never modify)
- **Working copy**: `/pscratch/sd/k/krydzy/SWE-agent/Lulesh_test/cuda/`
- **Upstream**: https://github.com/LLNL/LULESH (branch `2.0.2-dev`)
- **Executable**: `cuda/lulesh`

## Build

### g++-12 Requirement

**nvcc is incompatible with g++ 13+ when using `-std=c++11`.** Perlmutter defaults to g++ 13. The Makefile auto-detects g++-12:
```makefile
HOST_CXX ?= $(shell which g++-12 2>/dev/null || which g++-11 2>/dev/null || echo g++)
```

### Embedded Makefile

The Makefile is embedded in the build harness (`tools/lulesh_harness/bin/lulesh_build`) and generated on the fly if missing. This ensures the correct Perlmutter-adapted Makefile is always available even if the test repo's copy is modified or deleted.

### Via Harness (recommended)
```bash
module load python cmake openmpi/5.0.7 cuda/12.4
export LULESH_ROOT=/pscratch/sd/k/krydzy/SWE-agent/Lulesh_test/cuda
python3 tools/lulesh_harness/bin/lulesh_build          # standard build
python3 tools/lulesh_harness/bin/lulesh_build --clean   # clean rebuild
python3 tools/lulesh_harness/bin/lulesh_build --use-mpi # with MPI
```

### Manual Build
```bash
cd Lulesh_test/cuda
export HOST_CXX=$(which g++-12)
make -j8
```

## Run

### Via Harness (recommended)
```bash
python3 tools/lulesh_harness/bin/lulesh_run               # benchmark + correctness
python3 tools/lulesh_harness/bin/lulesh_run -s 30 -i 100  # custom parameters
python3 tools/lulesh_harness/bin/lulesh_check_correct      # quick correctness only
```

The harness: (1) builds pristine LULESH if needed, (2) runs pristine with identical parameters as baseline, (3) runs modified version, (4) compares Final Origin Energy (tolerance 1e-8), (5) compares wall-clock time for speedup, (6) outputs CORRECTNESS and SPEEDUP summary.

### Default Parameters
| Param | Default | Description |
|-------|---------|-------------|
| `-s` | 30 | Elements per side (total = s^3) |
| `-i` | 100 | Time step iterations |
| `-u` | -- | Unstructured mesh file (alt to `-s`) |

Quick correctness checks use `-s 20 -i 50`.

## Key Source Files
| File | Description |
|------|-------------|
| `cuda/src/lulesh.cu` | All CUDA kernels and host driver (~4800 lines) |
| `cuda/src/allocator.cu` | GPU memory pool allocator (reuses temporary allocations) |
| `cuda/Makefile` | Build config (generated by harness if missing) |

## Key CUDA Kernels (hot path)
| Kernel | Description |
|--------|-------------|
| `AddNodeForcesFromElems_kernel` | Scatter element forces to nodes (atomicAdd) |
| `CalcAccelerationForNodes_kernel` | F = ma per node |
| `ApplyAccelerationBoundaryConditions_kernel` | Symmetry BCs |
| `CalcPositionAndVelocity_kernel` | Update positions/velocities |
| `CalcKinematicsAndMonotonicQGradient_kernel` | Volume derivatives, velocity gradients, Q gradient |
| `CalcMonotonicQRegionForElems_kernel` | Monotonic artificial viscosity |
| `ApplyMaterialPropertiesAndUpdateVolume_kernel` | EOS, energy/pressure, volume update |
| `CalcTimeConstraintsForElems_kernel` | Reduction for dt constraints (shared memory) |
| `CalcMinDtOneBlock` | Final min-dt reduction |

## Memory Management

The `Allocator` class pools temporary GPU allocations -- caches freed blocks by size and reuses them instead of calling `cudaMalloc`/`cudaFree` per kernel. Critical for performance; do not replace with raw `cudaMalloc`.

## Output and Validation

### Correct Output (s=30, i=100)
```
Run completed:
   Problem size        =  30
   Iteration count     =  100
   Final Origin Energy = 3.293635e+03
Elapsed time         =       X.XX (s)
```

### Validation Regex Patterns
| Field | Pattern |
|-------|---------|
| Final Origin Energy | `Final Origin Energy\s*=\s*([\d.eE+-]+)` |
| Elapsed time | `Elapsed time\s*=\s*([\d.]+)` |

### Correctness

The harness extracts `Final Origin Energy` from both pristine and modified runs. Relative error must be < 1e-8 (`|modified - baseline| / |baseline|`).

## Common Issues

- **g++ 13 errors** -- Ensure `HOST_CXX` points to `g++-12`; embedded Makefile does this automatically.
- **"nvcc not found"** -- You are on a login node; CUDA builds require a compute node with GPUs.
- **Makefile missing** -- Run `lulesh_build`; it generates the Makefile from the embedded template.
- **CUDA sources missing after checkout** -- Older commits predate the CUDA port; skip them.
- **"Num processors must be a cube"** -- MPI builds need cube-number ranks (1, 8, 27, 64).
- **Volume/Q errors** -- Optimization broke the physics; revert. Error codes: VolumeError=-1, QStopError=-2.
- **Different iteration counts** -- Adaptive dt can shift with FP order changes; check Final Origin Energy instead.
